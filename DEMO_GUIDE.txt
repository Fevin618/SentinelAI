=====================================================================

=====================================================================

All commands are run in PowerShell (or Command Prompt) from the
project folder:

    cd D:\SentinelAI

We use the Anaconda Python, because it has scikit-learn 1.7.2,
the same version the saved models were trained with.

---------------------------------------------------------------------

    C:/Users/Admin/Anaconda/python.exe -m pip install -r requirements.txt

2. Check that the dataset is in place (8 CSV files):

   Shows the code works. Expected result: "19 passed".

    C:/Users/Admin/Anaconda/python.exe -m pytest -q tests

   If it does not open by itself, type that address into the browser.
   To stop it: press Ctrl + C in the terminal.

---------------------------------------------------------------------
PART 6 - LIKELY QUESTIONS AND SHORT ANSWERS
---------------------------------------------------------------------

Q: Why is the Wednesday result so low?
A: Wednesday's attacks (mostly DoS GoldenEye) look different from
   the training days. The random split puts similar records in both
   training and testing, which makes it look easier than real life.

Q: What is "true label"?
A: The correct answer from the dataset. The model never sees it; we
   only use it afterwards to grade the predictions.

Q: Why two Random Forests?
A: A controlled test: one with class weighting, one without. The
   weighting made almost no difference (20.0% vs 22.0%).

Q: What is SHAP?
A: A method that shows how much each feature pushed a single
   prediction towards attack or normal.

Q: How do you avoid data leakage?
A: Each model is a scikit-learn pipeline, so missing values are
   filled using the training data only. Wednesday is removed from
   training completely.

Q: What are "missing or invalid cells" (5,734)?
A: Mostly "Infinity" values from dividing by a zero-length connection
   time. We treat them as missing and fill them with the median
   learned from the training data.

Q: Does it monitor a live network?
A: No. It analyses stored or uploaded CSV records. Live capture is
   future work.

PART 7 - IF SOMETHING GOES WRONG
---------------------------------------------------------------------

  "streamlit is not recognized"
      -> Use the full command:
         C:/Users/Admin/Anaconda/python.exe -m streamlit run dashboard/app.py

  "Port 8501 is already in use"
      -> The dashboard is already running. Open http://localhost:8501
         or close the old terminal and start again.

      -> The CSV does not have the 78 expected columns. Use the
         Demo sample instead.

  Explain page is slow the first time
      -> Normal: SHAP takes a few seconds. Records already explained
         load instantly after that.

  Page looks stuck or old
      -> Press R in the browser (rerun), or refresh the page.
